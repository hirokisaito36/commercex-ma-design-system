01 / BRAND

ロゴとブランドマーク

CommerceX M&Aのロゴは、「交差」を意味するXを大胆なシルエットで表現しています。 売り手と買い手、事業と資本、機会とタイミングが交わる瞬間を象徴します。 必ず下記のバリエーションから背景に応じて選び、独自に色を作らないでください。

LOGO VARIATIONS — HORIZONTAL (PRIMARY)

標準ロゴ。Webサイトのヘッダー、名刺、プレゼン資料の表紙など、横長の余白がある場面で優先的に使用します。

Primary / 白背景logo.png
Mono reverse / ダーク背景logo-white.png
LOGO VARIATIONS — STACKED (SECONDARY)

縦組みロゴ。SNSアイコン、名刺の裏面、正方形〜縦長のフレーム、資料の章扉など、 コンパクトで存在感のある表示が必要な場面で使用します。

Primary / 白背景logo-stacked.png
Mono reverse / ダーク背景logo-stacked-white.png
CLEAR SPACE & MIN SIZE

余白 = Xマークの高さ分

ロゴ周囲にはXアイコン1個分以上の余白を確保してください。他の要素（テキスト、写真、罫線）は入れません。

最小サイズ

画面上 ロゴ高 ≥ 20px / 紙面上 10mm 以上。 これを下回る場合はXアイコン単体のみを使用してください。

DO / DON'T
✓
ダーク背景には白ロゴ（logo-white.png）を使う

黒・濃色面ではMono reverseの白ロゴで明確なコントラストを確保。Gold版ロゴは使用しません。

✓
表記は「CommerceX M&A」で統一

CとXは大文字、M&Aは大文字。「COMMERCEX M&A」「Commercex M&a」などの表記は使用しません。

✓
Goldアクセントは1画面1点に絞る

主役を明確にし、強いメッセージほど周囲に空間を。テキストアクセントとしてGold/Gold Lightを使う場合は背景に応じて選択。

✕
ロゴを拡大/縮小以外で変形しない

傾ける・色替え・グラデ・影付けは禁止。

✕
写真や柄の上に直置きしない

必ず単色面の上、またはCream/Surfaceの確保領域に配置。

✕
金額の前に「￥」を付けない

「8.4億円」「3,200万円」のように、円を後ろに付けて表記します。「￥8.4億」のような前置記号は使用しません。

05 / RADIUS

角丸

M&Aらしい「誠実さ」を担保するため、角丸は抑制的に使用します。 大きなコンテナほど丸みを小さく、カードやダイアログは --r-lg まで。ボタンは --r-sm で堅実に。

06 / SHADOW

シャドウ

誇張せず、紙面の層を表現するための薄い影。Goldシャドウはキーアクション（「面談予約」など）1つに限定します。

TOKENSAMPLEVALUEUSE

--sh-1 0 1px 2px rgba(17,17,17,.06) + 0 1px 1px rgba(17,17,17,.04) リスト行・下位のカード
--sh-2 0 4px 12px rgba(17,17,17,.08) + 0 1px 2px rgba(17,17,17,.04) カード・浮き要素（標準）
